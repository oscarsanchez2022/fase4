# Software FJ

Fase 4 curso de Programacion (213023), UNAD. Es un sistema diseñadoen Python para gestionar clientes, 
servicios y reservas de la empresa Software FJ, usando programacion orientada a objetos y manejo de excepciones. 
No usa base de datos todo se guarda en listas y solo se escribe un archivo de logs.
